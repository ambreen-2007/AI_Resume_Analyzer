AI Resume Analyzer and Job Matching App

About the Project

This is a beginner-friendly AI Resume Analyzer and Job Matching application built using Python and Streamlit.

Features

- Upload a resume in PDF format.
- Extract text from the resume.
- Analyze resume content.
- Match resume skills with job requirements.
- Display an analysis report.

Technologies Used

- Python
- Streamlit
- PDF Text Extraction
- VS Code

How to Run

1. Install Python.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the application using Streamlit.

Project Purpose

The purpose of this project is to help students understand resume analysis and job matching using Python.
